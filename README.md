# 주간 감정 회고 (Diary Analyzer)

하루 일기를 쓰면 AI가 감정을 분석하고, 일주일치를 모아 감정 흐름과 주간 리포트를 보여주는 개인 프로젝트입니다.

> ⚠️ AI 분석은 참고용이며 의학적 진단이 아닙니다.

## 만든 이유

[전역 후 일상에 적응하는 과정을 돌아보기 위해 / AI 도구 사용법을 익히기 위해]

## 주요 기능

- 날짜별 일기 작성과 저장
- 일기별 감정 점수(기쁨, 평온, 불안, 슬픔, 분노, 피로), 키워드, 한 줄 요약
- 감정 변화 그래프와 키워드 빈도 그래프
- AI 주간 리포트 생성
- AI 서버가 막혀도 일기는 먼저 저장되고, 나중에 다시 분석 가능

## 기술 스택

Python, Streamlit, pandas, Google Gemini API

## 실행 방법

1. 저장소를 내려받습니다.
2. 가상환경을 만들고 켭니다.
   ```
   python -m venv venv
   venv\Scripts\activate
   ```
3. 라이브러리를 설치합니다.
   ```
   pip install -r requirements.txt
   ```
4. `.env.example`을 복사해 `.env`로 이름을 바꾸고, 본인의 Gemini API 키를 넣습니다.
5. 샘플 데이터를 만들고 실행합니다.
   ```
   python create_sample.py
   streamlit run app.py
   ```

## 파일 설명

| 파일               | 역할                       |
| ------------------ | -------------------------- |
| `app.py`           | 화면(일기 쓰기, 주간 회고) |
| `analyze.py`       | 일기 한 편을 AI로 분석     |
| `create_sample.py` | 테스트용 가짜 데이터 생성  |
| `check_models.py`  | 사용 가능한 모델 진단      |

## 개인정보

일기는 분석을 위해 API로 외부 서버에 전송됩니다. 일기 데이터(`data/`)와 API 키(`.env`)는 저장소에 올라가지 않도록 `.gitignore`로 제외했습니다.
